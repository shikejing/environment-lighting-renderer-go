# environment-lighting-renderer-go

一个可复现的离线环境光照渲染器。场景由程序化描述生成，光照来自本地 HDR
环境贴图（Radiance `.hdr`），输出为 PNG 图像。渲染结果与线程数无关、
可取消、可断点续渲。

## 构建与运行

```sh
go build ./cmd/elr
./elr -w 640 -h 480 -samples 32 -grid 16 -seed 1234 -out render.png \
      -checkpoint render.ckpt -preview preview.png
```

中断（Ctrl-C 或 `-timeout`）后恢复：

```sh
./elr -w 640 -h 480 -samples 32 -grid 16 -seed 1234 \
      -checkpoint render.ckpt -resume -out render.png
```

## 采样模型（可复现性设计）

- 每个像素、每个采样轮次 `r` 使用独立随机流：种子为
  `HashSeed(seed, x, y, r)`（splitmix64 混合）。随机数只依赖
  （主种子， 像素坐标， 轮次），与调度、线程数完全无关。
- 相机为固定针孔相机，亚像素抖动来自上述随机流。
- 相机光线未命中场景时直接采样环境贴图（等距柱状投影，双线性插值，
  水平环绕、垂直截断）。
- 命中场景时估计直接环境光照：绕法线做一次余弦加权半球采样
  （cosine-weighted hemisphere），向该方向发阴影光线查询 BVH；
  未遮挡则贡献 `albedo * env(dir)`（余弦项与采样 pdf 相消）。
- 累积方式为逐像素按轮次顺序 0..N-1 累加浮点辐亮度。由于每个样本
  的值只依赖 （种子， 像素， 轮次），任意线程数、中断后续渲的结果
  与一次性渲染**逐比特一致**。

## 场景组织与增量更新

- 场景物体（球体）组织在 BVH 中。BVH 节点不可变，增删改沿根到叶
  路径写时复制（copy-on-write），只复制 O(深度) 个节点；子树叶子数
  超过上次构建时 2 倍时仅对该子树做局部重建，绝不每次全量重建。
- 每次更新原子地发布新快照（`atomic.Pointer` + 发布时复制图元表）。
  渲染持有旧快照，更新期间开始的渲染要么看到更新前、要么看到更新后
  的完整结构，绝不会读到半更新状态。更新完成后的查询结果与全量重建
  一致（测试 `TestIncrementalMatchesFullRebuild` 与暴力参考逐射线对比）。

## 渐进式渲染、取消与恢复

- 渲染按轮次渐进累积；每轮完成后：
  - 若配置了 `-checkpoint`，原子地写入检查点（临时文件 + rename，
    崩溃/取消不会留下半写入文件）；
  - 若配置了 `-preview`，原子地写出当前进度的预览 PNG（分块输出）。
- 通过 `context` 支持取消与超时（`-timeout`、SIGINT/SIGTERM）。中断
  时已完成的轮次全部保留在检查点中，最终输出文件不会被写入
  （CLI 以退出码 2 表示部分完成）。
- `-resume` 从检查点继续：检查点记录 （宽， 高， 总采样数， 种子，
  已完成轮数， 累积缓冲），配置不匹配时拒绝恢复。恢复后的累积结果
  与未中断的一次性渲染逐比特一致，不会重复叠加或漏掉轮次。

## 负载均衡

- 每轮把图像划分为 `-tile` 大小的分块，工作线程通过原子计数器从
  共享队列抢占分块（work stealing）。慢分块只影响其所在的一小片，
  不会拖垮整体吞吐；线程数增加时耗时可扩展（测试环境 4 核：
  1 线程 7.1s → 4 线程 2.0s，输出逐字节一致）。

## 色调映射（HDR → 显示范围）

`-tonemap clamp|reinhard|aces`，`-exposure`（线性曝光倍率，默认 1），
`-gamma`（显示伽马，默认 2.2）。

极端亮度行为（确定性，见 `internal/tonemap` 包文档与测试）：

- NaN 分量 → 0；
- +Inf → `MaxLuminance`（1e30），-Inf → 0；
- 负分量 → 0；超过 `MaxLuminance` 的分量截断到 `MaxLuminance`；
- 曝光后再次执行上述清理（曝光可能溢出到 +Inf）；
- 曲线输出截断到 [0,1] 后再做伽马。三种曲线均单调，极端输入下
  输出确定且落在 [0,1]。

## 配置项一览（`./elr -h`）

| 参数 | 默认 | 说明 |
|---|---|---|
| `-w` `-h` | 320x240 | 输出分辨率 |
| `-samples` | 16 | 每像素采样轮次 |
| `-seed` | 1234 | 渲染主种子 |
| `-threads` | NumCPU | 工作线程数（不影响结果） |
| `-tile` | 32 | 分块大小 |
| `-grid` | 12 | 程序化场景网格（grid² 个球 + 浮动球 + 地面） |
| `-scene-seed` | 42 | 场景生成种子 |
| `-env` | 空 | 本地 `.hdr` 环境贴图；空则程序化生成天空 |
| `-env-w` `-env-h` `-sun` | 512x256, 200 | 生成天空的参数（sun 可取 1e6 等极端值） |
| `-env-out` | 空 | 保存使用中的环境贴图为 `.hdr` |
| `-checkpoint` | 空 | 检查点路径（启用断点续渲） |
| `-resume` | false | 从检查点恢复 |
| `-preview` | 空 | 每轮写出预览 PNG |
| `-timeout` | 0 | 超时中断（如 30s） |
| `-tonemap` `-exposure` `-gamma` | aces, 1, 2.2 | 色调映射 |

## 测试

```sh
go test ./...          # 单元 + 端到端测试
go test -race ./...    # 竞态检测（含更新期间并发渲染）
```

覆盖：跨线程数/重复运行的逐比特可复现性、增量更新与全量重建一致性、
快照隔离、取消/超时后的检查点完整性与断点恢复一致性、极端亮度边界、
RGBE 读写往返、CLI 端到端输出一致性。
